# Безопасность / Security

## 🇷🇺 Как сообщить об уязвимости

Если вы нашли уязвимость в самом ContiTool — например, отчёт о проблеме уносит личные данные, которых не должен,
или специально подготовленный дамп заставляет программу выполнить чужой код, — **не публикуйте её в issue**.
Сообщите приватно: вкладка **Security → Report a vulnerability** в репозитории
([прямая ссылка](https://github.com/perkthefox/mqb_contitool/security/advisories/new)).

Опишите, что происходит, как это воспроизвести и какая версия. Исправления выходят в следующей версии; поддерживается
только последний релиз.

Это не канал для вопросов о том, как работают защитные функции автомобиля, и не канал техподдержки — для этого есть
[Discussions](https://github.com/perkthefox/mqb_contitool/discussions).

## 🇬🇧 Reporting a vulnerability

If you find a vulnerability in ContiTool itself — for example, a problem report carrying personal data it should not,
or a crafted dump making the program run someone else's code — **do not post it in an issue**. Report it privately
through the repository's **Security → Report a vulnerability** tab
([direct link](https://github.com/perkthefox/mqb_contitool/security/advisories/new)).

Describe what happens, how to reproduce it and which version. Fixes ship in the next release; only the latest release
is supported.

This is not a channel for questions about how vehicle security features work, nor for support — use
[Discussions](https://github.com/perkthefox/mqb_contitool/discussions) for that.
